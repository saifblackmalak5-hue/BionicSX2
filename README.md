# BionicSX2 🎮
> PS2 emulator for iPhone & iPad — based on ARMSX2/PCSX2

![Platform](https://img.shields.io/badge/platform-iOS%2016%2B-lightgrey)
![Status](https://img.shields.io/badge/status-In%20Development-orange)

## About
BionicSX2 is the first open-source PS2 emulator for iOS/iPadOS,
built on top of ARMSX2 and PCSX2 with Apple Silicon optimization.

## Requirements
- iPhone/iPad with A12 Bionic chip or newer
- iOS 16.0+
- PS2 BIOS (from legally owned console)
